The source of these fonts is https://github.com/olikraus/u8g2/tree/master/tools/font/bdf, with license information at: https://github.com/olikraus/u8g2/wiki/fntgrpx11

Copyright strings from the font files: "Public domain font. Share and enjoy." or "Public domain terminal emulator font.  Share and enjoy."

These are provided here for simplicity in .bdf and .pcf form, suitable for drop-in use in microcontrollers and similar languages that need bitmap fonts in bdf or pcf format, such as CircuitPython.

Slashes were added to zeros to make 0 (zero) more distinct from O (the uppercase letter between M and P)

There are also drastically reduced character set versions, again for use on microcontrollers where storage of all types is at a premium.

For typeface copyright issues, see also https://en.wikipedia.org/wiki/Eltra_Corp._v._Ringer
